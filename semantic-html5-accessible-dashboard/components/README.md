# Component inventory

This project uses small, native HTML components rather than a framework.

- **Site header:** brand, primary navigation, theme toggle, and responsive navigation button.
- **Workspace sidebar:** a separately labelled navigation landmark.
- **Metric card:** semantic `<article>` with a clear label and value.
- **Data table:** `<table>`, `<caption>`, `<thead>`, `<tbody>`, scoped headers, and labelled progress elements.
- **Form field:** visible `<label>`, native input/select/radio controls, helper text, and associated validation messages.
- **Modal dialog:** native `<dialog>` with a heading, description, close controls, validation summary, and focus restoration.
- **Status badge:** text label as well as color; color is not the only status indicator.
- **Progress bar:** native `<progress>` plus a programmatic accessible name.
- **Chart:** visible summary and a data table accompany the visual chart.

Use these as reference patterns when adding components. Keep visible focus indicators and keyboard access for every interactive control.
